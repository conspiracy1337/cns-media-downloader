# cns' media downloader

Downloads videos/audios from YouTube and other sites.  
Auto-installs [yt-dlp](https://github.com/yt-dlp/yt-dlp) and [ffmpeg](https://github.com/BtbN/FFmpeg-Builds) on first run.
